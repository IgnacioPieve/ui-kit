# Documentación de ui-kit

Índice de la documentación del proyecto. La estructura sigue el framework
[Diátaxis](https://diataxis.fr/): separa la documentación por su propósito
(aprender, consultar, entender, resolver una tarea).

| Documento | Tipo | Para qué sirve |
|---|---|---|
| [development.md](development.md) | How-to / Tutorial | Compilar el kit, publicar una versión, adoptarlo en una app nueva, troubleshooting. |
| [architecture.md](architecture.md) | Explanation | Decisiones de diseño: por qué CSS plano, por qué build dual, por qué `dist/` commiteado. |
| [components.md](components.md) | Reference | Todos los componentes y hooks exportados, con sus props. |
| [tokens.md](tokens.md) | Reference | Todos los tokens de color, radios y tipografía, y su mapeo a clases de Tailwind. |

Otros archivos relevantes en la raíz del repo:

- [`README.md`](../README.md) — qué es el kit y cómo se consume, en corto.
- [`CLAUDE.md`](../CLAUDE.md) — guía corta para agentes de IA que trabajen en el repo.
